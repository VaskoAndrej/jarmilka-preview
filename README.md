# JarMilka — náhľad webu

Klientsky náhľad nového vizuálu webu JarMilka, predajne vlasovej a telovej kozmetiky v Šali.

[Otvoriť náhľad webu](https://vaskoandrej.github.io/jarmilka-preview/)

Web tvorí samostatné HTML, CSS a JavaScript s lokálnymi obrázkami a písmami. Nevyžaduje zostavenie ani inštaláciu závislostí; na lokálny náhľad stačí otvoriť `index.html` v modernom prehliadači. Je pripravený aj pre GitHub Pages.

Táto verzia slúži na prezentáciu návrhu. Obsahuje pokyn pre vyhľadávače, aby náhľad neindexovali. Odkazy na mapu, sociálne siete a kontaktné aplikácie vedú na externé služby.

Licencie použitých písiem sú uložené v `assets/fonts/`.
